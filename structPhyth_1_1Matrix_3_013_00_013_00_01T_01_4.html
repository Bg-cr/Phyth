Detailed Description

template<typename T>
struct Phyth::Matrix< 3, 3, T >

3x3 matrix with Quantity components

Matrix3x3 stores three column vectors, enabling matrix-vector operations while preserving physical dimensions.

Template Parameters
TComponent type (must be a Quantity instantiation)

Example: Matrix3x3<Quantity<Meter>> m; // 3x3 matrix with meter components auto result = m * Vector3<Quantity<Meter>>(1.0_m, 0_m, 0_m);
