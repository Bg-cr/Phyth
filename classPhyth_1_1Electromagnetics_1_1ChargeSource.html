Detailed Description

Abstract base class for all charge distributions.

ChargeSource defines the interface for any charge distribution that produces an electric field and potential. Subclasses represent specific geometries such as point charges, line charges, surface charges, volume charges, or dipoles.

The interface provides methods for computing:

  • Electric field E at a point
  • Electric potential V at a point
  • Total charge (integrated over the source)
  • Charge density at a point (for distributed sources)
  • Minimum distance from a point to the source (for regularization)

Example: class PointCharge : public ChargeSource { // Implements GetElectricFieldAt, GetElectricPotentialAt, // GetTotalChargeValue, GetMinimumDistanceTo };
