Detailed Description

Concentrated force acting at a single point in an elastic medium.

Produces a stress field via Kelvin's solution (Green's function for an infinite elastic medium).

Formula: sigma_ij(vec_r) = - (1 / (8 * pi * (1 - nu))) * [ (1 - 2*nu) * (vec_F_i * vec_r_j + vec_F_j * vec_r_i - delta_ij * (vec_F dot vec_r)) / r^3

  • 3 * (vec_F dot vec_r) * vec_r_i * vec_r_j / r^5 ]

Example:

auto force = std::make_shared<PointForce>(
origin,
force,
material
);
elastic_field.AddSource(force);
