Detailed Description

template<typename T>
struct Phyth::Quaternion< T >

Quaternion with Quantity components.

A quaternion represents rotations in 3D space. It consists of a scalar part (w) and a vector part (x, y, z).

This implementation uses Quantity types for all components, ensuring that quaternion operations are dimensionally consistent. For rotation quaternions, all components should be dimensionless (Scalar type).

Template Parameters
TComponent type (must be a Quantity instantiation, typically Scalar)

Example: using Rotation = Quaternion<Scalar>;

// Rotate a vector by 90 degrees around Z axis auto q = Rotation::FromAxisAngle(Vector3<Scalar>(0, 0, 1), 90.0_deg); auto v = Vector3<Quantity<Meter>>(1.0_m, 0_m, 0_m); auto rotated = q.Rotated(v); // (0_m, 1_m, 0_m)
