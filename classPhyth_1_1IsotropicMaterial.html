Detailed Description

Linear elastic isotropic material model.

IsotropicMaterial implements the constitutive relationship for linear elastic materials with direction-independent mechanical properties. The material is fully defined by any two independent elastic constants, with automatic derivation of all other parameters.

The stress-strain relationship follows Hooke's law: sigma_ij = lambda * delta_ij * epsilon_kk + 2 * mu * epsilon_ij

where lambda is Lame's first parameter and mu is the shear modulus.

Supported material parameter pairs for construction:

  • (Young's modulus E, Poisson's ratio nu)
  • (Shear modulus G, Bulk modulus K)

All quantities maintain physical dimensions through the Quantity system, ensuring dimensional consistency at compile time.

Example: // Steel-like material IsotropicMaterial steel(210.0e9_Pa, 0.3);

// Compute stress from strain Matrix3x3<Scalar> strain = ...; auto stress = steel.ComputeStress(strain);

Construct from Young's modulus and Poisson's ratio.

This is the most common construction method for engineering materials. All other elastic constants (shear modulus G, bulk modulus K, and Lame's first parameter lambda) are derived automatically.

Valid range: -1 < nu < 0.5 for thermodynamic stability

  • nu > 0.5: material becomes incompressible or auxetic
  • nu < -1: violates stability criteria

Compute strain tensor from stress tensor.

Implements the inverse form of Hooke's law: epsilon_ij = (1 + nu) / E * sigma_ij - nu / E * trace(sigma) * delta_ij

This is the compliance form of the constitutive relationship, useful for displacement-based formulations.

Parameters
stressStress tensor in pascals (symmetric)
Returns
Strain tensor (dimensionless, symmetric)

Example: Matrix3x3<Quantity<Pascal>> stress; stress(0, 0) = 100.0e6_Pa; // uniaxial tension auto strain = material.ComputeStrain(stress);

Compute stress tensor from strain tensor.

Implements the generalized Hooke's law for isotropic materials: sigma_ij = lambda * trace(epsilon) * delta_ij + 2 * mu * epsilon_ij

The strain tensor is expected to represent infinitesimal strain (small deformation theory). For finite strain, use appropriate hyperelastic models instead.

Parameters
strainStrain tensor (dimensionless, symmetric)
Returns
Stress tensor in pascals (symmetric)

Example: Matrix3x3<Scalar> strain; strain(0, 0) = 0.001; // 0.1% axial strain auto stress = material.ComputeStress(strain);

◆ UpdateDerivedParameters()

void Phyth::IsotropicMaterial::UpdateDerivedParameters ( )
inlineprivate

Update derived parameters from (E, nu)

Relations: G = E / (2 * (1 + nu)) K = E / (3 * (1 - 2 * nu)) lambda = E * nu / ((1 + nu) * (1 - 2 * nu))

Note: These formulas are singular for nu = 0.5 (incompressible limit) and nu = -1 (stability limit).

void Phyth::IsotropicMaterial::UpdateDerivedParametersFromGK ( )
inlineprivate

Update derived parameters from (G, K)

Relations: E = 9 * G * K / (3 * K + G) nu = (3 * K - 2 * G) / (2 * (3 * K + G)) lambda = K - 2/3 * G

This formulation is more stable near the incompressible limit.
