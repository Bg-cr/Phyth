template<typename VariableEnum >
FormulaSolver & Phyth::FormulaSolver< VariableEnum >::Solve ( )
inline

Executes the solving routine. State is automatically saved before solving.

For a formula with N variables, the solver loops through each variable, treating it as unknown and all others as known, then computes and stores the result. Snapshots are saved before each solve to enable rollback.
