Detailed Description

Magnetic field composed of multiple magnetic sources.

MagneticField aggregates multiple MagneticSource objects and computes the total magnetic field at any point by summing their contributions.

This class implements the Field interface, returning a Vector3 of Tesla quantities (magnetic flux density B).

Example: MagneticField field;

auto dipole = std::make_shared<MagneticDipole>(...); field.AddSource(dipole);

auto point = Vector3<Quantity<Meter>>(1.0_m, 0_m, 0_m); auto B = field.GetValueAt(point); // Total B-field at that point
