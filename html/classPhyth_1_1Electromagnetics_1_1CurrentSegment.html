Detailed Description

Magnetic field from a straight current-carrying wire segment.

CurrentSegment computes the magnetic field generated by a finite straight wire segment carrying a steady current, using the Biot-Savart law in closed form.

The magnetic field direction follows the right-hand rule around the current direction (from start to end).

Example: auto start = Vector3<Quantity<Meter>>(-1.0_m, 0_m, 0_m); auto end = Vector3<Quantity<Meter>>(1.0_m, 0_m, 0_m); auto current = 5.0_A;

CurrentSegment wire(start, end, current); auto point = Vector3<Quantity<Meter>>(0_m, 0.1_m, 0_m); auto B = wire.GetMagneticFieldAt(point);

Note: The field is singular on the wire axis. Points on the wire will throw an exception.

Vector3< Quantity< Tesla > > Phyth::Electromagnetics::CurrentSegment::AnalyticSolution ( const Vector3< Quantity< Meter > > &  point) const
inlineprivate

Closed-form Biot-Savart solution for a finite straight wire.

The magnetic field at a point P is: B = (mu_0 * I / (4 * pi * rho)) * (z2/sqrt(rho^2 + z2^2) - z1/sqrt(rho^2 + z1^2)) * phi_hat

where:

  • rho is the perpendicular distance from P to the wire axis
  • z1, z2 are the distances from the projection point to the ends
  • phi_hat is the azimuthal unit vector around the wire
Parameters
pointPosition to evaluate the field
Returns
Magnetic field at that point

If rho is near zero (point on the wire axis), returns zero instead of throwing. The singularity is handled by the caller.
