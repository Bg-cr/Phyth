Detailed Description

template<typename UnitT>
struct Phyth::Quantity< UnitT >

Physical quantity with a value and a compile-time unit.

Quantity is the primary user-facing type. It stores a numeric value and carries a unit type that encodes both dimension (SI exponents) and scale (e.g., meter vs. kilometer).

Template Parameters
UnitTA unit type (e.g., Unit<Length, std::ratio<1>>)

Example: Quantity<Meter> length = 5.0_m; Quantity<Second> time = 3.0_s; auto speed = length / time; // Quantity<Velocity> with value ~1.666...
