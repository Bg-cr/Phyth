Detailed Description

Singleton registry for unit names and symbols.

UnitRegistry stores display information for unit types. It is used by QuantityToString() to print human-readable unit names instead of raw dimension strings (e.g., "J" instead of "m^2*kg*s^-2").

The registry is thread-safe via a mutex.

Usage: // Register a unit manually UnitRegistry::GetInstance().RegisterUnit<Meter>("Meter", "m");

// Register a unit at static initialization time using UnitRegistrar static UnitRegistrar<Meter> meterRegistrar("Meter", "m");

// Retrieve registered info auto name = UnitRegistry::GetInstance().GetName<Meter>(); // "Meter" auto symbol = UnitRegistry::GetInstance().GetSymbol<Meter>(); // "m"
