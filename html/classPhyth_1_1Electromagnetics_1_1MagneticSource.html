Detailed Description

Abstract base class for all magnetic field sources.

MagneticSource defines the interface for any object that produces a magnetic field. Subclasses represent specific sources such as:

  • Current-carrying wire segments
  • Magnetic dipoles
  • Solenoids
  • Permanent magnets

Example: class MagneticDipole : public MagneticSource { [[nodiscard]] Vector3<Quantity<Tesla>> GetMagneticFieldAt(const Vector3<Quantity<Meter>>& point) const override { // Compute dipole field at point return B; } };
