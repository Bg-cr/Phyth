Detailed Description

template<typename UnitT>
struct Phyth::UnitRegistrar< UnitT >

Static registrar for unit types.

UnitRegistrar registers a unit at static initialization time, before main() is called. This allows units to be registered automatically without requiring explicit registration calls.

Template Parameters
UnitTThe unit type to register

Usage: // In a .cpp file or header (with inline): static UnitRegistrar<Meter> meterRegistrar("Meter", "m"); static UnitRegistrar<Second> secondRegistrar("Second", "s"); static UnitRegistrar<Newton> newtonRegistrar("Newton", "N");
